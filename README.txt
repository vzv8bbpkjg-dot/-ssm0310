# My Planner PWA

このフォルダはPWA公開用の基本一式です。

## 公開手順（GitHub Pages）
1. GitHubで新しいリポジトリを作成（公開設定）。
2. このZIPを解凍し、中の5ファイルをリポジトリのルートにアップロード。
3. Settings → Pages → Deploy from a branch → `main` / root を選び保存。
4. 発行されたHTTPS URLをSafariで開く。
5. Safariの共有 →「ホーム画面に追加」でインストール。

## 注意
- PWAはHTTPSで配信される必要があります（GitHub PagesはHTTPS対応）。
- 初回はオンラインで開いてキャッシュを作る必要があります。
- HTML内の保存機能は端末・ブラウザ内の保存領域を使います。ブラウザデータ消去やアプリ削除でデータが消える可能性があるため、ZIPバックアップを定期的に保存してください。
- PWA化だけでiOSのバックグラウンド通知が常時動作する保証はありません。
- このパッケージはPWA設定を追加したもので、iPhone実機での操作テストは未実施です。
